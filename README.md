# paper_temp-thresh-shash
 

## Overview
This is the code for the paper titled "Identifying the Timing of Regional Summertime Minimum Temperature Threshold Crossings and the Potential Subsequent Climate Evolutions" to be published in Earth's Future. 

## Pytorch 
This code was written with python version = 3.11.6, numpy version = 1.24.4, xarray version = 2023.6.0, pytorch version = 2.4.1. The YAML file in this repository contains the environment.
